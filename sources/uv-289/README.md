# CSC-289: Programming Capstone Project

**Course ID**: CSC-289
**Course Title**: Programming Capstone Project
**Credits**: 3 (1 Class, 4 Lab, 0 Clinical, 0 Work)
**Duration**: 16 weeks
**Instructor**: Andrew Norris
**Cross-Program Collaboration**: GRD-242 (Graphic Design IV) - Weeks 2-8

---

## Course Description

This course provides an opportunity to complete a significant programming project from the design phase through implementation with minimal instructor support. Emphasis is placed on project definition, testing, presentation, and implementation. Upon completion, students should be able to complete a project from the definition phase through implementation.

**Prerequisite Courses**: CTI-110, CTI-120, and CTS-115

---

## Course Philosophy: Process Over Product

CSC-289 emphasizes **professional software development processes** over perfect code. Students are assessed primarily on:
- Project management execution (60% of grade)
- Cross-team collaboration quality (embedded in process grade)
- Adaptive planning and problem-solving
- Professional communication and documentation
- Technical deliverables (40% of grade)

**Safe-to-Fail Environment**: Retrospectives, iteration, and transparent failure documentation are rewarded, not penalized.

---

## Course Learning Outcomes (CLOs)

Upon completion of this course, students will be able to:

1. **Manage a software project autonomously** using industry-standard Agile/Scrum practices from ideation through deployment. *(Creating, Applying)*

2. **Collaborate effectively with cross-functional teams** (designers, stakeholders) using professional communication protocols and dependency management strategies. *(Applying, Evaluating)*

3. **Evaluate and integrate external design assets** using user story acceptance criteria and technical constraint validation. *(Evaluating, Analyzing)*

4. **Adapt project plans** in response to changing requirements, technical blockers, and stakeholder feedback using risk management and scope control techniques. *(Evaluating, Creating)*

5. **Document technical and process decisions** through comprehensive project artifacts (sprint planning, retrospectives, risk registers, process portfolios). *(Creating, Analyzing)*

6. **Execute professional development workflows** including version control, code review, testing, and deployment to production. *(Applying, Creating)*

## Course Structure

### **Module 1: Red Clearance Recertification (Week 1)**
Verify mastery of Sacred Flow GitHub workflow and autonomous PM capability through hands-on certification.

**Graded Deliverables**:
- M01-A1: Project Charter & Work Breakdown Structure (50 pts)
- M01-A2: Product Backlog & Release Roadmap (50 pts)

### **Modules 2-5: GRD-242 Collaboration Sprints (Weeks 2-8)**
Execute 4 two-week sprints while collaborating with GRD-242 graphic design students on visual asset development.

**Graded Deliverables (per sprint)**:
- Sprint Planning Document (10 pts)
- Sprint Technical Implementation (20 pts)
- Sprint Process Artifacts (standup logs, burndown, retrospective) (15 pts)
- **Cross-Team Collaboration Artifacts** (design brief, feedback documentation, integration evidence) (5 pts)

**Special Collaboration Milestones**:
- **Week 6: Design Brief Presentation** to GRD-242 students (25 pts)
- **Week 7: Design Feedback & Iteration Cycle** documentation (25 pts)
- **Week 8: Design Asset Integration** and acceptance testing (25 pts)

### **Modules 6-8: Solo Development Sprints (Weeks 9-16)**
Continue sprint cycles independently, refine features, manage technical debt, and prepare final delivery.

**Graded Deliverables (per sprint)**:
- Sprint Planning & Execution (30 pts)
- Sprint Process Artifacts (20 pts)

### **Module 8: Final Delivery (Week 16)**
Complete capstone project with comprehensive process portfolio demonstrating PM mastery journey.

**Graded Deliverables**:
- M08-A1: Final Project Technical Deliverable (100 pts)
- M08-A2: Process Portfolio & Presentation (75 pts)

## Cross-Program Collaboration: GRD-242 Integration

### **The Client-Developer Model**

**CSC-289 students (Developers)**: Define project vision, write design requirements, evaluate design deliverables, integrate assets into working software.

**GRD-242 students (Design Agency)**: Receive creative briefs, develop brand identity and visual campaign assets, present design strategies, iterate based on technical feedback.

### **Collaboration Timeline**

**Weeks 2-5**: Initial sprints with design needs identification
**Week 6**: CSC students present design briefs to GRD class (3/4 through GRD course)
**Week 7**: Design iteration and feedback cycles
**Week 8**: Final design asset delivery and integration

### **Graded Collaboration Touchpoints**

1. **Design Brief Presentation (Week 6, 25 pts)**: Formal presentation to GRD-242 class including project vision, technical demo, design requirements, technical constraints, and timeline.

2. **Design Feedback Documentation (Week 7, 25 pts)**: GitHub Issues/PRs documenting professional feedback cycles using evaluation framework.

3. **Design Asset Integration (Week 8, 25 pts)**: Pull requests integrating final design assets with acceptance testing and designer attribution.

## Success Criteria

**Red Clearance (Week 1)**: Pass/Fail checkpoint
- ✅ Project charter approved
- ✅ Complete estimated backlog
- ✅ Realistic release roadmap
- ✅ Comprehensive risk register
- ✅ GitHub workflow demonstrated

**Sprint Success (Each sprint)**:
- ✅ Sprint planning complete before sprint starts
- ✅ Minimum 8 standup entries per 2-week sprint
- ✅ Working software demo at sprint review
- ✅ Retrospective completed within 2 days of sprint end
- ✅ Action items from retrospective implemented

**Collaboration Success (Weeks 2-8)**:
- ✅ Professional communication with GRD students
- ✅ Clear technical constraints documented
- ✅ Constructive design feedback provided
- ✅ Design assets integrated successfully
- ✅ Designer attribution in project credits

**Capstone Success (Week 16)**:
- ✅ MVP functional and deployed
- ✅ All PM artifacts complete and professional
- ✅ Process portfolio demonstrates mastery
- ✅ Reflection shows PM growth journey
