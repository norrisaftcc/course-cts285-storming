🛡 Red Clearance: What This Means

This is your capstone gateway.

Red Clearance is a pass/fail checkpoint that proves you have the PM fundamentals to operate autonomously. In CTS-285, you learned Agile and Sacred Flow with guided support. In CSC-289, you are the project manager. This module verifies you're ready.

What You Must Demonstrate:

  • Sacred Flow mastery: repo creation, branching, PRs, and merges without hand-holding
  • Agile vocabulary fluency: sprint, velocity, backlog, user story, acceptance criteria
  • Charter-level scoping: define what your capstone will deliver and how you'll measure success
  • Roadmap realism: plan around the GRD-242 collaboration timeline, not in a vacuum

Why This Matters: Students who skip PM foundations build the wrong thing. This checkpoint ensures your capstone starts on solid ground.

🔬 Hands-On Activity: Sacred Flow Verification Lab

What you'll do:

This lab proves you can execute the Sacred Flow workflow independently. No step-by-step instructions this time — you've done this before in CTS-285. Now demonstrate it from memory.

What You'll Practice:

  • Creating a GitHub repository with proper README, .gitignore, and license

  • Creating a feature branch, making commits, and opening a pull request
  • Writing a meaningful PR description and performing self-review

Success Criteria:

  • Repository exists with branch protection enabled
  • At least one completed PR with description and merge
  • Screenshots document the full Sacred Flow cycle
  • No direct commits to main branch

💡 Andrew's Tips for Success

  • This is not CTS-285 again: Red Clearance is a verification, not a tutorial. If you're struggling with Sacred Flow basics, revisit your CTS-285 materials before proceeding — you'll need these skills every single week.
  • Scope is everything: The #1 capstone killer is scope creep. Define what your MVP is — and more importantly, what it is NOT. Write it down. Defend it.
  • Plan around GRD-242: Your roadmap must account for design assets arriving from the graphic design students. Build in buffer time. Assume designs will be late (they often are).
  • Your backlog is a living document: The backlog you submit this week will evolve. That's expected. But starting with a solid, estimated backlog puts you weeks ahead of teams that "figure it out as they go."
  • Treat this like a job interview: Your Project Charter is the kind of document you'd present to a client or executive sponsor. Write it at that level. This is capstone — professional quality is the minimum standard.

📣 Andrew's Note

Welcome to CSC-289 — the capstone. This is where everything you've learned comes together. You're not learning new frameworks this semester; you're proving you can execute. Red Clearance exists because I've seen students jump into coding without a plan and waste three weeks building something nobody asked for.

Week 1 is intentionally intense. I'm compressing an entire planning module into one week because you should already have these skills. If the Entry Ticket or Sacred Flow lab feels easy, good — that means CTS-285 did its job. If it feels hard, come to office hours immediately. We need to fix gaps now, not in Week 5.

Your capstone project is your portfolio piece. Employers will see this. Treat every deliverable like it's going on your resume — because it is.
